# Surge — Fitness App Landing Page

A dark-mode, high-energy landing page concept for a fitness app, built as a single static HTML file (no build step, no dependencies).

## Sections

- **Hero** — bold headline, primary/secondary CTAs, and a floating stats preview
- **Workout library** — 6 workout types with duration and intensity indicators
- **Progress dashboard demo** — streak, calories, weekly chart, and personal records
- **Trainer profiles** — 4 coach cards with specialty and rating
- **Pricing** — 3 subscription tiers with a highlighted "Most Popular" plan

## Design

Near-black background with electric orange/red and lime-green accents. Type pairing: **Anton** (display) + **Manrope** (body), loaded from Google Fonts. All icons are inline SVG — no images or external assets.

## Usage

Open `index.html` directly in a browser, or serve the folder with any static file host (GitHub Pages, Vercel, Netlify, etc). The layout targets a desktop viewport (~1440px); it is not yet responsive for mobile widths.

## Content note

Trainer names, ratings, and usage stats are illustrative sample content for this concept design, not real data.
